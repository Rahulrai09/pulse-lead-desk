# Pulse theme layout backup

Known-good page templates for the pulsemotion.in Shopify theme (saved 26 Nov 2026).

**Why:** Shopify's "Update theme" button replaces the `main` section of every page
template with the plain Horizon default (product, collection, blog, article, rent,
donate and contact pages). The custom Pulse sections are still in the theme; only
these template files need putting back.

**How to restore:** duplicate the live theme, upload these files to the copy
(`templates/*.json`), check the preview, then publish the copy.
